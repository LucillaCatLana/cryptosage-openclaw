# 🦞 CryptoSage — AI Crypto Education Bot

> **Binance OpenClaw AI Competition 2026**

CryptoSage is an AI-powered crypto education assistant built on top of the Binance ecosystem. It helps beginners and intermediate users learn crypto, understand the market, and make smarter decisions — all in one place.

🌐 **Live Demo:** [Try it here]([https://lucillacatlana.github.io/cryptosage-openclaw/cryptosage-binance.html]))

---

## ✨ Features

### 🤖 AI Chat Assistant
Ask anything about crypto — Bitcoin, DeFi, trading strategies, Binance features. Powered by LLaMA 3.3 70B via Groq API. Responds in Ukrainian 🇺🇦 or English 🇬🇧.

### 📈 Live Market Data
- Real-time price ticker (BTC, ETH, BNB, SOL, XRP, DOGE, ADA, AVAX, DOT, LINK)
- Live charts with 6 coins and 4 timeframes (1h, 4h, 1d, 1w) via Binance API
- Market stats: Market Cap, Volume, BTC Dominance, Fear & Greed Index, BTC Fees

### 🔮 Crypto Oracle
Type any coin — get an AI-powered market sentiment analysis with a live score (0–100), animated gauge, and a dramatic AI prophecy. Unique feature you won't find anywhere else.

### 🔔 Smart Alerts
Set a price target for any coin — your browser sends a notification the moment it hits. No more refreshing Binance every 5 minutes.

### 📐 DCA Calculator
Set your investment goal, timeframe and frequency — the bot calculates exactly how much to buy weekly/monthly to reach your target. Fetches live prices from Binance.

### 🎮 Guess the Term Game
Learn crypto vocabulary through a fun guessing game. 21 terms, hints, and XP rewards.

### 🏆 XP & Level System
Earn XP for every question asked and game won. Level up as you learn.

### 🔥 Top Gainers & Losers
Real-time top movers from Binance — filtered by volume, no leveraged tokens.

### 📰 Crypto News
Latest headlines from CoinTelegraph via RSS feed.

## 🌐 Bilingual
Full Ukrainian 🇺🇦 and English 🇬🇧 support — UI, AI responses, game hints, everything.

## 🛠 Tech Stack

- **Frontend:** Vanilla HTML, CSS, JavaScript (single file, no frameworks)
- **AI:** LLaMA 3.3 70B via Groq API
- **Market Data:** Binance REST API, CoinGecko API
- **Sentiment:** Alternative.me Fear & Greed API
- **News:** CoinTelegraph RSS

cd cryptosage-openclaw
